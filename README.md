Bank Management System
Description
This is a simple Bank Management System developed in C++ using Object-Oriented Programming (OOP) concepts. The project allows users to manage bank accounts and perform basic banking operations.

Features
Create different account types
Deposit money
Withdraw money
Display account information
Calculate interest
Menu-driven interface
OOP Concepts Used
Classes & Objects
Inheritance
Encapsulation
Polymorphism
Account Types
Savings Account
Checking Account
Fixed Deposit Account
How to Run
Compile
g++ bank.cpp -o bank
Run
./bank

1. Show Accounts
2. Deposit

4. Calculate Interest
